# SOKONI 
## About the project
Sokoni is a digital marketplace designed to bridge the physical gap between sellers and buyers. 
It is a convenient way for buyers and sellers to trade goods.

## Features
- User registration and login
- Browse and explore available products
- Add products to a shopping cart
- Sellers can upload and manage their products

## Technologies Used
### Frontend
- React 
- Javascript
- Vite 
- HTML
- CSS

### Backend
- Python 
- Django 

### Database
- SQlite
